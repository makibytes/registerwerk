# ERC-721 Tokens (NFTs)

ERC-721 is the standard for non-fungible tokens (NFTs) on Ethereum-compatible blockchains. Unlike ERC-20, each ERC-721 token has a unique identifier and is not interchangeable with any other token in the collection.

## What does "non-fungible" mean in securities?

In the context of securities, non-fungibility makes sense when individual units have distinct characteristics. For example:

- A bond with a specific serial number and unique coupon terms
- A structured product where each unit references a different underlying asset
- A debenture issued to a specific named party with individual terms

Each of these is represented as a unique ERC-721 token with its own on-chain identifier.

## Token metadata

Each ERC-721 token can carry metadata describing the specific security it represents. In the registry, this metadata is stored on IPFS and includes:

- ISIN and any unit-level identifier
- Face value and coupon terms (if applicable)
- Issuance date
- Reference to the prospectus or term sheet

Metadata is set at issuance and is immutable after deployment.

## How it works in the registry

An issuer creating an ERC-721 issuance:

1. Specifies the total number of tokens (e.g., 500 bonds with unique serial numbers)
2. Each token is assigned a sequential `tokenId` starting from 1
3. Tokens are minted to the issuer's wallet and distributed individually to investors
4. Each investor receives a specific `tokenId`, recorded in the registry

## Checking your holdings

ERC-721 holdings in the portal show:

- The `tokenId` of each token you own
- The metadata for that specific token
- The full transfer history for that specific `tokenId`

## Limitations

- Transferring 100 ERC-721 tokens requires 100 separate transactions (or use ERC-1155 for batching)
- Not suitable for fractional ownership of a single asset
- Higher gas cost compared to ERC-20 for equivalent numbers of transfers

## When to choose ERC-721

Choose ERC-721 when:
- Each issued unit needs a unique, permanent identifier on-chain
- You want rich per-unit metadata stored immutably
- The number of units is relatively small (under a few thousand)

For large numbers of fungible units, [ERC-20](./erc20) or [ERC-3643](./erc3643) are more appropriate.
