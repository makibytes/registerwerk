# ERC-721 — Token no fungible { #erc-721-non-fungible-token }

ERC-721 emite un token único e indivisible por unidad. Cada token tiene un `tokenId` distinto. Esto lo hace adecuado para instrumentos donde la individualidad importa: bonos únicos, certificados numerados o instrumentos inmobiliarios de una sola propiedad.

---

## Cuándo usar ERC-721 { #when-to-use-erc-721 }

- **Certificados de bonos numerados**: donde cada bono es un instrumento legal distinto con su propio número de certificado
- **Tokens de bienes raíces**: cada propiedad como un token único y no divisible
- **Productos coleccionables o estructurados**: perfiles de pago únicos por token
- **Instrumentos de una sola unidad**: donde no se pretende dividir ni fusionar

Para valores fungibles (intercambiables), utilice [ERC-20](erc20.md) o [ERC-3643](erc3643.md). Para instrumentos semifungibles con múltiples unidades por tramo, use [ERC-3525](erc3525.md).

---

## Extensiones de Registerwerk ERC-721 { #registerwerk-erc-721-extensions }

El contrato `EwpgERC721` amplía el estándar ERC-721 con:

| Ampliación | Propósito |
|---|---|
| Enumerable | Permite la enumeración en cadena de todos los ID de token — usada por el indexador |
| `setTokenURI(tokenId, uri)` | Vincula el token a metadatos fuera de la cadena (prospecto, condiciones) |
| `freeze(address)` | Congelación de la capa de registro (se asigna a `HolderBlock`) |
| `setRegistryRef(tokenId, assetId)` | Vincula con `Asset` y `AssetHolder` de Registerwerk |

## Metadatos del certificado { #certificate-metadata }

El URI de metadatos de cada token ERC-721 apunta a un documento JSON almacenado en S3 que contiene:

```json
{
  "name": "Bond Certificate #1042",
  "isin": "DE000A3H3V72",
  "issuanceDate": "2025-01-15",
  "denomination": "10000",
  "currency": "EUR",
  "maturityDate": "2030-01-15",
  "registryRef": "asset-uuid",
  "holderRef": "legal-entity-uuid"
}
```

Los metadatos URI se almacenan en `AssetDeployment.metadataUri` y se actualizan cuando cambian los campos relevantes (por ejemplo, cambio de titular después de la transferencia).

---

## `AssetHolder` para ERC-721 { #assetholder-for-erc-721 }

Cada `tokenId` de ERC-721 se asigna exactamente a un registro `AssetHolder`. El campo `AssetHolder.tokenId` almacena el ID del token específico que posee ese inversor, lo que permite un seguimiento preciso de qué certificado pertenece a cada titular.
