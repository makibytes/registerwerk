# ERC-1155 — Multi-Token { #erc-1155-multi-token }

ERC-1155 permite que un único contrato administre múltiples tipos de tokens (tanto fungibles como no fungibles) simultáneamente. Cada tipo tiene su propio `id`. Las operaciones por lotes (batch mint, transferencia por lotes) reducen significativamente los costos de transacción para carteras con muchos instrumentos.

---

## Cuándo usar ERC-1155 { #when-to-use-erc-1155 }

- **Carteras de activos múltiples**: múltiples tipos de instrumentos emitidos bajo un contrato de programa
- **Emisión por lotes** — grandes asignaciones simultáneas (por ejemplo, distribución a 500 inversores en una sola transacción)
- **Fungible/no fungible mixto**: algunas unidades son fungibles (acciones), algunas son únicas (certificados)

Para implementaciones de un solo activo, [ERC-20](erc20.md) o [ERC-3643](erc3643.md) son más simples. ERC-1155 es más adecuado para emisores de programas que administran varios instrumentos bajo un único contrato marco.

---

## ID de tokens y mapeo de activos { #token-ids-and-asset-mapping }

Cada `tokenId` de ERC-1155 se asigna a un registro `Asset` independiente en Registerwerk. Cuando un operador implementa un programa multitoken:

1. Se implementa un **contrato de programa** (un `AssetDeployment` con `isMultiTokenProgramme = true`)
2. Cada instrumento en el programa tiene su propio `tokenId` rastreado en `AssetDeployment.tokenId`
3. Los saldos por inversor por tipo de token se rastrean en `AssetHolder` con el campo `tokenId`

---

## Operaciones por lotes { #batch-operations }

El `Erc1155DeploymentService` expone operaciones por lotes:

| Operación | Descripción |
|---|---|
| `batchMint(ids[], amounts[], address)` | Acuñar múltiples tipos de tokens en una dirección |
| `batchTransfer(ids[], amounts[], from, to)` | Transferir varios tipos en una sola transacción |
| `batchFreeze(addresses[])` | Congelar varias direcciones a la vez (extensión EwpgERC1155) |

Las operaciones por lotes reducen los costos de gas en aproximadamente un 70 % en comparación con las operaciones secuenciales de un solo tipo.
