# ERC-721 — Token non fungibile { #erc-721-non-fungible-token }

ERC-721 emette un token unico e indivisibile per unità. Ogni token ha uno `tokenId` distinto. Ciò lo rende adatto per strumenti in cui l'individualità conta: obbligazioni uniche, certificati numerati o strumenti immobiliari a proprietà singola.

---

## Quando utilizzare ERC-721 { #when-to-use-erc-721 }

- **Certificati obbligazionari numerati** — dove ciascuna obbligazione è uno strumento legale distinto con il proprio numero di certificato
- **Token immobiliari** — ogni proprietà come token unico e non divisibile
- **Prodotti da collezione o strutturati** — profili di rendimento unici per token
- **Strumenti a unità singola** — dove non è prevista la divisione o la fusione

Per titoli fungibili (intercambiabili), utilizzare [ERC-20](erc20.md) o [ERC-3643](erc3643.md). Per strumenti semifungibili con più unità per tranche, utilizzare [ERC-3525](erc3525.md).

---

## Estensioni Registerwerk ERC-721 { #registerwerk-erc-721-extensions }

Il contratto `EwpgERC721` estende lo standard ERC-721 con:

| Estensione | Scopo |
|---|---|
| Enumerabile | Consente l'enumerazione in catena di tutti gli ID token, utilizzati dall'indicizzatore |
| `setTokenURI(tokenId, uri)` | Collega il token ai metadati off-chain (prospetto, termini) |
| `freeze(address)` | Blocco del livello del registro (mappa su `HolderBlock`) |
| `setRegistryRef(tokenId, assetId)` | Collegamenti a Registerwerk `Asset` e `AssetHolder` |

## Metadati del certificato { #certificate-metadata }

L'URI dei metadati di ciascun token ERC-721 punta a un documento JSON archiviato in S3, contenente:

```json
{
  "name": "Bond Certificate #1042",
  "isin": "DE000A3H3V72",
  "issuanceDate": "2025-01-15",
  "denomination": "10000",
  "currency": "EUR",
  "maturityDate": "2030-01-15",
  "registryRef": "asset-uuid",
  "holderRef": "legal-entity-uuid"
}
```

I metadati URI vengono memorizzati in `AssetDeployment.metadataUri` e aggiornati quando cambiano i campi rilevanti (ad esempio, cambio titolare dopo il trasferimento).

---

## `AssetHolder` per ERC-721 { #assetholder-for-erc-721 }

Ogni `tokenId` ERC-721 è mappato esattamente su un record `AssetHolder`. Il campo `AssetHolder.tokenId` memorizza l'ID token specifico detenuto da quell'investitore, consentendo il monitoraggio preciso di quale certificato appartiene a quale titolare.
