# ERC-1155 — Multi-jeton { #erc-1155-multi-token }

ERC-1155 permet à un seul contrat de gérer plusieurs types de jetons (à la fois fongibles et non fongibles) simultanément. Chaque type possède son propre `id`. Les opérations par lots (émission par lots, transfert par lots) réduisent considérablement les coûts de transaction pour les portefeuilles comportant de nombreux instruments.

---

## Quand utiliser ERC-1155 { #when-to-use-erc-1155 }

- **Portefeuilles multi-actifs** — plusieurs types d'instruments émis sous un même contrat de programme
- **Émission par lots** — attributions simultanées de grande taille (par exemple, distribution à 500 investisseurs en une seule transaction)
- **Mixte fongible/non fongible** — certaines unités sont fongibles (actions), d'autres sont uniques (certificats)

Pour les déploiements d'actifs uniques, [ERC-20](erc20.md) ou [ERC-3643](erc3643.md) sont plus simples. ERC-1155 est le mieux adapté aux émetteurs de programmes gérant plusieurs instruments dans le cadre d'un seul contrat-cadre.

---

## Correspondance des tokenId et des actifs { #token-ids-and-asset-mapping }

Chaque `tokenId` ERC-1155 correspond à un enregistrement `Asset` distinct dans Registerwerk. Lorsqu'un opérateur déploie un programme multi-token :

1. Un **contrat programme** est déployé (un `AssetDeployment` avec `isMultiTokenProgramme = true`)
2. Chaque instrument du programme obtient son propre `tokenId` suivi dans `AssetDeployment.tokenId`
3. Les soldes par investisseur et par type de jeton sont suivis dans `AssetHolder` avec le champ `tokenId`

---

## Opérations par lots { #batch-operations }

Le `Erc1155DeploymentService` expose les opérations par lots :

| Opération | Description |
|---|---|
| `batchMint(ids[], amounts[], address)` | Émettre (mint) plusieurs types de jetons vers une seule adresse |
| `batchTransfer(ids[], amounts[], from, to)` | Transférer plusieurs types en une seule transaction |
| `batchFreeze(addresses[])` | Geler plusieurs adresses à la fois (extension EwpgERC1155) |

Les opérations par lots réduisent les coûts de gas d'environ 70 % par rapport aux opérations séquentielles d'un seul type.
