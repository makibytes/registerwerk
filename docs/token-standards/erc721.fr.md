# ERC-721 — Jeton non fongible { #erc-721-non-fungible-token }

ERC-721 émet un jeton unique et indivisible par unité. Chaque jeton possède un `tokenId` distinct. Cela le rend adapté aux instruments où l'individualité compte : obligations uniques, certificats numérotés ou instruments immobiliers à propriété unique.

---

## Quand utiliser ERC-721 { #when-to-use-erc-721 }

- **Certificats d'obligations numérotés** — où chaque obligation est un instrument juridique distinct avec son propre numéro de certificat
- **Jetons immobiliers** — chaque propriété en tant que jeton unique et non divisible
- **Produits de collection ou structurés** — profils de paiement uniques par jeton
- **Instruments à unité unique** — où la division ou la fusion n'est pas prévue

Pour les titres fongibles (interchangeables), utilisez [ERC-20](erc20.md) ou [ERC-3643](erc3643.md). Pour les instruments semi-fongibles avec plusieurs unités par tranche, utilisez [ERC-3525](erc3525.md).

---

## Registerwerk ERC-721 extensions { #registerwerk-erc-721-extensions }

Le contrat `EwpgERC721` étend la norme ERC-721 avec :

| Extension | Objectif |
|---|---|
| Énumérable | Permet l'énumération en chaîne de tous les ID de jeton - utilisé par l'indexeur |
| `setTokenURI(tokenId, uri)` | Lie le jeton aux métadonnées hors chaîne (prospectus, termes) |
| `freeze(address)` | Gel de la couche de registre (mappé sur `HolderBlock`) |
| `setRegistryRef(tokenId, assetId)` | Liens vers Registerwerk `Asset` et `AssetHolder` |

## Métadonnées du certificat { #certificate-metadata }

L'URI de métadonnées de chaque jeton ERC-721 pointe vers un document JSON stocké dans S3 contenant :

```json
{
  "name": "Bond Certificate #1042",
  "isin": "DE000A3H3V72",
  "issuanceDate": "2025-01-15",
  "denomination": "10000",
  "currency": "EUR",
  "maturityDate": "2030-01-15",
  "registryRef": "asset-uuid",
  "holderRef": "legal-entity-uuid"
}
```

Les métadonnées URI sont stockées dans `AssetDeployment.metadataUri` et mises à jour lorsque les champs pertinents changent (par exemple, changement de titulaire après le transfert).

## `AssetHolder` pour ERC-721 { #assetholder-for-erc-721 }

Chaque `tokenId` ERC-721 correspond à exactement un enregistrement `AssetHolder`. Le champ `AssetHolder.tokenId` stocke l'ID de jeton spécifique détenu par cet investisseur, permettant un suivi précis de quel certificat appartient à quel titulaire.
