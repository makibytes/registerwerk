# Solana SPL-2022

**Token-2022** (also known as **Token Extensions** or **SPL-2022**) is Solana's next-generation token program that extends the classic SPL Token program with a rich set of **extensions** configurable at mint creation time. Registerwerk uses SPL-2022 for Solana-native security tokens.

---

## Supported token types

| Token enum | Description | Key extensions used |
|---|---|---|
| `SPL` | Classic Solana SPL token | Minimal — standard transfer only |
| `SPL_2022` | SPL-2022 base | TransferFee, MetadataPointer |
| `SPL_2022_BOND` | Interest-bearing bond | InterestBearing, TransferFee, PermanentDelegate |
| `SPL_2022_CONFIDENTIAL` | Privacy-preserving token | ConfidentialTransfer, TransferFee |

---

## Key SPL-2022 extensions in use

### InterestBearing

Used for `SPL_2022_BOND`. Computes accrued interest continuously at a configured rate. The on-chain balance grows over time without requiring explicit coupon transactions. `AssetBondTerms.couponRate` is stored in this extension's configuration at mint creation.

The corporate actions engine reads the accrued interest at coupon payment dates and settles it as a separate payment to avoid accounting ambiguity.

### ConfidentialTransfer

Used for `SPL_2022_CONFIDENTIAL`. Uses ElGamal encryption to shield transfer amounts while allowing the mint authority (Registerwerk operator) to audit all transactions. This enables privacy for investor positions while maintaining regulatory oversight.

!!! warning "ElGamal public key required"
    The confidential transfer extension requires an ElGamal public key for the mint authority. This key must be generated and stored securely before deploying a confidential SPL-2022 token.

### PermanentDelegate

Used for `SPL_2022_BOND`. Grants the Registerwerk operator wallet permanent delegated authority over all token accounts, enabling force-transfer and force-burn operations required by the registry's legal authority under eWpG §16 and TVTG.

### TransferFee

Allows a configurable fee to be withheld from every transfer, sent to a fee account. Used to automatically collect registry fees on secondary-market transfers.

### TransferHook

Used to invoke a custom Solana program on every transfer. In Registerwerk, the transfer hook program implements investor validation checks (equivalent to ERC-3643's compliance module): it verifies that the destination account's associated identity has a valid KYC claim before allowing the transfer.

## Deployment

`SolanaTokenService` handles SPL-2022 deployment:

1. Configures the mint account with the appropriate extensions
2. Initialises the mint authority as the operator's Solana wallet
3. Creates a registry entry in `AssetDeployment` with `contractAddress = mintAddress`
4. For `SPL_2022_BOND`: sets `InterestBearing.rate = couponRate` from `AssetBondTerms`

---

## Indexer

The Solana indexer (using Helius or Shyft WebSocket) subscribes to:
- Account change notifications on tracked mint addresses
- Transfer events (parsed from transaction logs)
- Interest accrual events (for `SPL_2022_BOND`)

Results are written to the `token_transfer` table, consistent with the EVM indexer output.
