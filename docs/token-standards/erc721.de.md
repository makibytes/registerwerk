# ERC-721 – Nicht fungibler Token { #erc-721-non-fungible-token }

ERC-721 gibt einen einzigartigen, unteilbaren Token pro Einheit aus. Jeder Token hat ein eigenes
`tokenId`. Dies macht es für Instrumente geeignet, bei denen es auf Individualität ankommt –
einzigartige Anleihen, nummerierte Zertifikate oder Immobilieninstrumente für Einzelobjekte.

---

## Wann ERC-721 verwenden { #when-to-use-erc-721 }

- **Nummerierte Anleihezertifikate** – bei denen jede Anleihe ein eigenständiges
  Rechtsinstrument mit eigener Zertifikatsnummer ist
- **Immobilien-Token** – jede Immobilie als einzigartiger, nicht teilbarer Token
- **Sammelbare oder strukturierte Produkte** – einzigartige Auszahlungsprofile pro Token
- **Instrumente mit einer Einheit** – wobei eine Aufteilung oder Zusammenführung nicht
  beabsichtigt ist

Für fungible (austauschbare) Wertpapiere verwenden Sie [ERC-20](erc20.md) oder
[ERC-3643](erc3643.md). Für semi-fungible Instrumente mit mehreren Einheiten pro Tranche
verwenden Sie [ERC-3525](erc3525.md).

---

## Registerwerk-ERC-721-Erweiterungen { #registerwerk-erc-721-extensions }

Der `EwpgERC721`-Vertrag erweitert den Standard-ERC-721 mit:

| Erweiterung | Zweck |
|---|---|
| Enumerable | Ermöglicht die On-Chain-Aufzählung aller Token-IDs – verwendet vom Indexer |
| `setTokenURI(tokenId, uri)` | Verknüpft Token mit Off-Chain-Metadaten (Prospekt, Bedingungen) |
| `freeze(address)` | Freeze auf Registerebene (zugeordnet zu `HolderBlock`) |
| `setRegistryRef(tokenId, assetId)` | Verknüpfung zu Registerwerks `Asset` und `AssetHolder` |

## Zertifikatsmetadaten { #certificate-metadata }

Die Metadaten-URI jedes ERC-721-Tokens verweist auf ein in S3 gespeichertes JSON-Dokument, das
Folgendes enthält:

```json
{
  "name": "Bond Certificate #1042",
  "isin": "DE000A3H3V72",
  "issuanceDate": "2025-01-15",
  "denomination": "10000",
  "currency": "EUR",
  "maturityDate": "2030-01-15",
  "registryRef": "asset-uuid",
  "holderRef": "legal-entity-uuid"
}
```

Die Metadaten-URI wird in `AssetDeployment.metadataUri` gespeichert und aktualisiert, wenn sich
relevante Felder ändern (z. B. Inhaberwechsel nach einer Übertragung).

## `AssetHolder` für ERC-721 { #assetholder-for-erc-721 }

Jede ERC-721-`tokenId` wird genau einem `AssetHolder`-Datensatz zugeordnet. Im Feld
`AssetHolder.tokenId` wird die spezifische, von diesem Anleger gehaltene Token-ID gespeichert,
sodass genau nachverfolgt werden kann, welches Zertifikat zu welchem Inhaber gehört.
