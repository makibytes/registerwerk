# ERC-1155 – Multi-Token { #erc-1155-multi-token }

ERC-1155 ermöglicht die gleichzeitige Verwaltung mehrerer Tokentypen (sowohl fungibel als auch
nicht fungibel) mit einem einzigen Vertrag. Jeder Typ hat seinen eigenen `id`. Batch-Operationen
(Batch Mint, Batch Transfer) reduzieren die Transaktionskosten bei Portfolios mit vielen
Instrumenten erheblich.

---

## Wann ERC-1155 verwenden { #when-to-use-erc-1155 }

- **Multi-Asset-Portfolios** – mehrere Instrumententypen, ausgegeben unter einem einzigen
  Programmvertrag
- **Stapelausgabe** – große gleichzeitige Zuteilungen (z. B. Verteilung an 500 Anleger in einer
  einzigen Transaktion)
- **Gemischt fungibel/nicht fungibel** – einige Einheiten sind fungibel (Aktien), andere sind
  einzigartig (Zertifikate)

Für Einzelasset-Bereitstellungen sind [ERC-20](erc20.md) oder [ERC-3643](erc3643.md) einfacher.
ERC-1155 eignet sich am besten für Programmemittenten, die mehrere Instrumente unter einem
einzigen Rahmenvertrag verwalten.

---

## Token-IDs und Asset-Zuordnung { #token-ids-and-asset-mapping }

Jede ERC-1155-`tokenId` wird einem eigenen `Asset`-Eintrag in Registerwerk zugeordnet. Wenn ein
Betreiber ein Multi-Token-Programm bereitstellt:

1. Es wird ein **Programmvertrag** bereitgestellt (ein `AssetDeployment` mit
   `isMultiTokenProgramme = true`)
2. Jedes Instrument im Programm erhält seinen eigenen `tokenId`, der in
   `AssetDeployment.tokenId` verfolgt wird
3. Salden pro Anleger und Token-Typ werden in `AssetHolder` im Feld `tokenId` erfasst

---

## Batch-Operationen { #batch-operations }

Der `Erc1155DeploymentService` stellt Batch-Operationen bereit:

| Operation | Beschreibung |
|---|---|
| `batchMint(ids[], amounts[], address)` | Mehrere Token-Typen an eine Adresse prägen |
| `batchTransfer(ids[], amounts[], from, to)` | Mehrere Typen in einer Transaktion übertragen |
| `batchFreeze(addresses[])` | Mehrere Adressen gleichzeitig einfrieren (EwpgERC1155-Erweiterung) |

Batch-Vorgänge reduzieren die Gaskosten um ~70 % im Vergleich zu sequentiellen Einzeltyp-Vorgängen.
