# ERC-1155 — Multi-Token { #erc-1155-multi-token }

ERC-1155 consente a un singolo contratto di gestire più tipi di token (sia fungibili che non fungibili) contemporaneamente. Ogni tipo ha il proprio `id`. Le operazioni batch (conio batch, trasferimento batch) riducono significativamente i costi di transazione per i portafogli con molti strumenti.

---

## Quando utilizzare ERC-1155 { #when-to-use-erc-1155 }

- **Portafogli multi-asset** — più tipi di strumenti emessi nell'ambito di un unico contratto di programma
- **Emissione batch** — grandi assegnazioni simultanee (ad esempio, distribuzione a 500 investitori in un'unica transazione)
- **Fungibili/non fungibili misti** — alcune unità sono fungibili (azioni), alcune sono uniche (certificati)

Per distribuzioni di asset singoli, [ERC-20](erc20.md) o [ERC-3643](erc3643.md) sono più semplici. ERC-1155 è particolarmente adatto per gli emittenti di programmi che gestiscono diversi strumenti nell'ambito di un unico contratto quadro.

---

## ID token e mappatura delle risorse { #token-ids-and-asset-mapping }

Ogni `tokenId` ERC-1155 mappa su un record `Asset` separato in Registerwerk. Quando un operatore implementa un programma multi-token:

1. Viene distribuito un **contratto di programma** (uno `AssetDeployment` con `isMultiTokenProgramme = true`)
2. Ogni strumento nel programma ha il proprio `tokenId` tracciato in `AssetDeployment.tokenId`
3. I saldi per investitore e per tipo di token vengono tracciati in `AssetHolder` con il campo `tokenId`

---

## Operazioni batch { #batch-operations }

`Erc1155DeploymentService` espone le operazioni batch:

| Operazione | Descrizione |
|---|---|
| `batchMint(ids[], amounts[], address)` | Conia più tipi di token in un unico indirizzo |
| `batchTransfer(ids[], amounts[], from, to)` | Trasferisci più tipi in un'unica transazione |
| `batchFreeze(addresses[])` | Blocca più indirizzi contemporaneamente (estensione EwpgERC1155) |

Le operazioni batch riducono i costi del gas di circa il 70% rispetto alle operazioni sequenziali di tipo singolo.
