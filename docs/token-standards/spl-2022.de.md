# Solana SPL-2022 { #solana-spl-2022 }

**Token-2022** (auch bekannt als **Token Extensions** oder **SPL-2022**) ist Solanas
Token-Programm der nächsten Generation, das das klassische SPL-Token-Programm um einen
umfangreichen Satz an **Erweiterungen** ergänzt, die bei der Mint-Erstellung konfigurierbar sind.
Registerwerk verwendet SPL-2022 für Solana-native Wertpapier-Token.

---

## Unterstützte Token-Typen { #supported-token-types }

| Token-Enum | Beschreibung | Verwendete Schlüsselerweiterungen |
|---|---|---|
| `SPL` | Klassischer Solana-SPL-Token | Minimal – nur Standardübertragung |
| `SPL_2022` | SPL-2022-Basis | TransferFee, MetadataPointer |
| `SPL_2022_BOND` | Verzinsliche Anleihe | InterestBearing, TransferFee, PermanentDelegate |
| `SPL_2022_CONFIDENTIAL` | Datenschutzwahrender Token | ConfidentialTransfer, TransferFee |

---

## Wichtige verwendete SPL-2022-Erweiterungen { #key-spl-2022-extensions-in-use }

### InterestBearing { #interestbearing }

Verwendet für `SPL_2022_BOND`. Berechnet die aufgelaufenen Zinsen kontinuierlich zu einem
konfigurierten Zinssatz. Der On-Chain-Saldo wächst mit der Zeit, ohne dass explizite
Kupon-Transaktionen erforderlich sind. `AssetBondTerms.couponRate` wird bei der Mint-Erstellung in
der Konfiguration dieser Erweiterung gespeichert.

Die Corporate-Actions-Engine liest die aufgelaufenen Zinsen an den Kuponzahlungsterminen und
verrechnet sie als separate Zahlung, um buchhalterische Unklarheiten zu vermeiden.

### ConfidentialTransfer { #confidentialtransfer }

Verwendet für `SPL_2022_CONFIDENTIAL`. Verwendet ElGamal-Verschlüsselung, um Transferbeträge
abzuschirmen, während gleichzeitig die Mint Authority (Registerwerk-Betreiber) alle Transaktionen
prüfen kann. Das ermöglicht Vertraulichkeit der Anlegerpositionen bei gleichzeitiger
Aufrechterhaltung der behördlichen Aufsicht.

!!! warning "Öffentlicher ElGamal-Schlüssel erforderlich"
    Die ConfidentialTransfer-Erweiterung erfordert einen öffentlichen ElGamal-Schlüssel für die
    Mint Authority. Dieser Schlüssel muss vor der Bereitstellung eines vertraulichen
    SPL-2022-Tokens generiert und sicher gespeichert werden.

### PermanentDelegate { #permanentdelegate }

Verwendet für `SPL_2022_BOND`. Gewährt der Registerwerk-Betreiber-Wallet dauerhafte delegierte
Autorität über alle Token-Konten und ermöglicht so Force-Transfer- und Force-Burn-Vorgänge, die
von der gesetzlichen Befugnis des Registers gemäß eWpG §16 und TVTG gefordert werden.

### TransferFee { #transferfee }

Erlaubt es, bei jeder Übertragung eine konfigurierbare Gebühr einzubehalten und an ein
Gebührenkonto zu senden. Wird verwendet, um bei Sekundärmarkttransfers automatisch Registergebühren
zu erheben.

### TransferHook { #transferhook }

Wird verwendet, um bei jeder Übertragung ein benutzerdefiniertes Solana-Programm aufzurufen. In
Registerwerk implementiert das Transfer-Hook-Programm Anlegervalidierungsprüfungen (entspricht dem
Compliance-Modul von ERC-3643): Es prüft, ob die mit dem Zielkonto verknüpfte Identität über einen
gültigen KYC-Anspruch verfügt, bevor die Übertragung zugelassen wird.

## Bereitstellung { #deployment }

`SolanaTokenService` übernimmt die SPL-2022-Bereitstellung:

1. Konfiguriert das Mint-Konto mit den entsprechenden Erweiterungen
2. Initialisiert die Mint Authority als Solana-Wallet des Betreibers
3. Erstellt einen Registereintrag in `AssetDeployment` mit `contractAddress = mintAddress`
4. Für `SPL_2022_BOND`: setzt `InterestBearing.rate = couponRate` aus `AssetBondTerms`

---

## Indexer { #indexer }

Der Solana-Indexer (über Helius- oder Shyft-WebSocket) abonniert:
- Kontoänderungsbenachrichtigungen für verfolgte Mint-Adressen
- Übertragungsereignisse (aus Transaktionsprotokollen analysiert)
- Zinsabgrenzungsereignisse (für `SPL_2022_BOND`)

Die Ergebnisse werden in die Tabelle `token_transfer` geschrieben, konsistent mit der Ausgabe des
EVM-Indexers.
