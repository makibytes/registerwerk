# Solana SPL-2022 { #solana-spl-2022 }

**Token-2022** (noto anche come **Token Extensions** o **SPL-2022**) è il programma token di nuova generazione di Solana che estende il classico programma Token SPL con un ricco set di **estensioni** configurabile al momento della creazione della zecca. Registerwerk utilizza SPL-2022 per security token nativi di Solana.

---

## Tipi di token supportati { #supported-token-types }

| Enumerazione token | Descrizione | Principali estensioni utilizzate |
|---|---|---|
| `SPL` | Token classico Solana SPL | Minimo: solo trasferimento standard |
| `SPL_2022` | Base SPL-2022 | TransferFee, MetadataPointer |
| `SPL_2022_BOND` | Obbligazione fruttifera | InterestBearing, TransferFee, PermanentDelegate |
| `SPL_2022_CONFIDENTIAL` | Token con tutela della privacy | ConfidentialTransfer, TransferFee |

---

## Principali estensioni SPL-2022 in uso { #key-spl-2022-extensions-in-use }

### InterestBearing { #interestbearing }

Utilizzato per `SPL_2022_BOND`. Calcola continuamente gli interessi maturati a un tasso configurato. Il saldo sulla catena cresce nel tempo senza richiedere transazioni di cedola esplicite. `AssetBondTerms.couponRate` viene memorizzato nella configurazione di questa estensione al momento della creazione della zecca.

Il motore delle azioni aziendali legge gli interessi maturati alle date di pagamento della cedola e li liquida come pagamento separato per evitare ambiguità contabili.

### ConfidentialTransfer { #confidentialtransfer }

Utilizzato per `SPL_2022_CONFIDENTIAL`. Utilizza la crittografia ElGamal per proteggere gli importi dei trasferimenti consentendo allo stesso tempo all'autorità della zecca (operatore Registerwerk) di controllare tutte le transazioni. Ciò garantisce la privacy per le posizioni degli investitori mantenendo al contempo la supervisione normativa.

!!! warning "Chiave pubblica ElGamal richiesta"
    L'estensione di trasferimento confidenziale richiede una chiave pubblica ElGamal per l'autorità della zecca. Questa chiave deve essere generata e archiviata in modo sicuro prima di distribuire un token SPL-2022 riservato.

### PermanentDelegate { #permanentdelegate }

Utilizzato per `SPL_2022_BOND`. Concede al portafoglio dell'operatore Registerwerk un'autorità delegata permanente su tutti i conti token, consentendo le operazioni di trasferimento coattivo e di distruzione forzata richieste dall'autorità legale del registro ai sensi dell'eWpG §16 e del TVTG.

### TransferFee { #transferfee }

Consente di trattenere una commissione configurabile da ogni trasferimento, inviata a un conto a pagamento. Utilizzato per riscuotere automaticamente le commissioni di registro sui trasferimenti sul mercato secondario.

### TransferHook { #transferhook }

Utilizzato per richiamare un programma Solana personalizzato su ogni trasferimento. In Registerwerk, il programma di hook di trasferimento implementa controlli di convalida degli investitori (equivalenti al modulo di conformità di ERC-3643): verifica che l'identità associata dell'account di destinazione abbia un'attestazione KYC valida prima di consentire il trasferimento.

## Distribuzione { #deployment }

`SolanaTokenService` gestisce la distribuzione SPL-2022:

1. Configura l'account mint con le estensioni appropriate
2. Inizializza l'autorità di zecca come portafoglio Solana dell'operatore
3. Crea una voce di registro in `AssetDeployment` con `contractAddress = mintAddress`
4. Per `SPL_2022_BOND`: imposta `InterestBearing.rate = couponRate` da `AssetBondTerms`

---

## Indicizzatore { #indexer }

L'indicizzatore Solana (utilizzando Helius o Shyft WebSocket) si iscrive a:
- Notifiche di modifica dell'account sugli indirizzi di mint monitorati
- Eventi di trasferimento (analizzati dai registri delle transazioni)
- Eventi di maturazione degli interessi (per `SPL_2022_BOND`)

I risultati vengono scritti nella tabella `token_transfer`, coerente con l'output dell'indicizzatore EVM.
