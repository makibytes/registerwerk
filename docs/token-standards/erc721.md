# ERC-721 — Non-Fungible Token

ERC-721 issues a unique, indivisible token per unit. Each token has a distinct `tokenId`. This makes it suitable for instruments where individuality matters — unique bonds, numbered certificates, or single-property real-estate instruments.

---

## When to use ERC-721

- **Numbered bond certificates** — where each bond is a distinct legal instrument with its own certificate number
- **Real-estate tokens** — each property as a unique, non-divisible token
- **Collectible or structured products** — unique payoff profiles per token
- **Single-unit instruments** — where splitting or merging is not intended

For fungible (interchangeable) securities, use [ERC-20](erc20.md) or [ERC-3643](erc3643.md). For semi-fungible instruments with multiple units per tranche, use [ERC-3525](erc3525.md).

---

## Registerwerk ERC-721 extensions

The `EwpgERC721` contract extends standard ERC-721 with:

| Extension | Purpose |
|---|---|
| Enumerable | Allows on-chain enumeration of all token IDs — used by indexer |
| `setTokenURI(tokenId, uri)` | Links token to off-chain metadata (prospectus, terms) |
| `freeze(address)` | Registry-layer freeze (maps to `HolderBlock`) |
| `setRegistryRef(tokenId, assetId)` | Links to Registerwerk `Asset` and `AssetHolder` |

## Certificate metadata

Each ERC-721 token's metadata URI points to a JSON document stored in S3 containing:

```json
{
  "name": "Bond Certificate #1042",
  "isin": "DE000A3H3V72",
  "issuanceDate": "2025-01-15",
  "denomination": "10000",
  "currency": "EUR",
  "maturityDate": "2030-01-15",
  "registryRef": "asset-uuid",
  "holderRef": "legal-entity-uuid"
}
```

The metadata URI is stored in `AssetDeployment.metadataUri` and updated when relevant fields change (e.g., holder change after transfer).

---

## `AssetHolder` for ERC-721

Each ERC-721 `tokenId` maps to exactly one `AssetHolder` record. The `AssetHolder.tokenId` field stores the specific token ID held by that investor, allowing precise tracking of which certificate belongs to which holder.
