*[eWpG]: Gesetz über elektronische Wertpapiere — the German Electronic Securities Act, in force since June 2021, which allows a security to exist as a register entry instead of a paper certificate.
*[ISIN]: International Securities Identification Number — the 12-character code that uniquely identifies a security worldwide.
*[LEI]: Legal Entity Identifier — a 20-character code that uniquely identifies a company in financial markets.
*[KYC]: Know Your Customer — the checks a regulated firm must run to establish who it is dealing with.
*[AML]: Anti-Money Laundering — the rules preventing the financial system from being used to disguise criminal proceeds.
*[DvP]: Delivery versus Payment — settling so that the security moves if and only if the money moves.
*[NAV]: Net Asset Value — what one unit of a fund or vault is worth.
*[LTV]: Loan-to-Value — how much you have borrowed as a percentage of what your collateral is worth.
*[LLTV]: Liquidation Loan-to-Value — the LTV threshold above which a loan may be liquidated.
*[APR]: Annual Percentage Rate — an interest rate expressed per year.
*[bps]: Basis points — hundredths of a percent. 100 bps = 1%.
*[MiCAR]: Markets in Crypto-Assets Regulation — the EU regulation covering crypto-asset issuers and service providers.
*[EMT]: E-Money Token — a MiCAR crypto-asset that references a single official currency.
*[DORA]: Digital Operational Resilience Act — the EU regulation on ICT risk for financial entities.
*[MiFIR]: Markets in Financial Instruments Regulation — the EU regulation behind transaction reporting.
*[DAC8]: The EU directive extending automatic tax information exchange to crypto-assets.
*[CARF]: Crypto-Asset Reporting Framework — the OECD standard behind DAC8.
*[TFR]: Transfer of Funds Regulation — the EU rule requiring originator and beneficiary information to travel with a transfer.
*[DSGVO]: Datenschutz-Grundverordnung — the German name for the GDPR.
*[GDPR]: General Data Protection Regulation — the EU data protection law.
*[DSAR]: Data Subject Access Request — a person's request to see the personal data held about them.
*[DPIA]: Data Protection Impact Assessment — a structured analysis of privacy risk required for high-risk processing.
*[TVTG]: Token- und VT-Dienstleister-Gesetz — Liechtenstein's Token and Trusted Technology Service Provider Act.
*[CSSF]: Commission de Surveillance du Secteur Financier — Luxembourg's financial regulator.
*[AMF]: Autorité des marchés financiers — France's financial markets regulator.
*[BaFin]: Bundesanstalt für Finanzdienstleistungsaufsicht — Germany's financial supervisory authority.
*[ERC]: Ethereum Request for Comments — the numbering scheme for Ethereum token standards.
*[EVM]: Ethereum Virtual Machine — the execution environment that Ethereum and compatible chains share.
*[T-REX]: Token for Regulated EXchanges — the compliance framework standardised as ERC-3643.
*[ONCHAINID]: The on-chain identity contract that holds a party's verified claims under ERC-3643.
*[SPL]: Solana Program Library — Solana's equivalent of Ethereum's token standards.
*[DAML]: The smart-contract language used by the Canton network.
*[RPC]: Remote Procedure Call — the interface through which software talks to a blockchain node.
*[JWT]: JSON Web Token — the signed token that carries your identity between browser and server.
*[TOTP]: Time-based One-Time Password — the six-digit rotating code produced by an authenticator app.
*[MFA]: Multi-Factor Authentication — proving who you are with more than one kind of evidence.
*[2FA]: Two-Factor Authentication — multi-factor authentication with exactly two factors.
*[SSO]: Single Sign-On — signing in once with your employer's account instead of a separate password.
*[OIDC]: OpenID Connect — the standard protocol for delegating sign-in to an identity provider.
*[TAP]: Temporary Access Pass — a short-lived Microsoft Entra credential used to recover an account.
*[CA]: Conditional Access — Microsoft Entra's policy engine for deciding when to demand more proof of identity.
*[API]: Application Programming Interface — the machine-readable interface to a system.
*[REST]: Representational State Transfer — the common style of HTTP API used throughout Registerwerk.
*[UUID]: Universally Unique Identifier — a 128-bit identifier, written as 32 hex characters.
*[SEPA]: Single Euro Payments Area — the European bank transfer scheme.
*[OCI]: Open Container Initiative — the standard behind container images and their digests.
*[SLO]: Service Level Objective — a target for how reliable a service should be.
*[ICT]: Information and Communication Technology.
*[CREATE2]: The Ethereum opcode that lets a contract address be computed before deployment.
